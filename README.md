### Required input files in `data/`

After downloading the dataset, place the following CSV files directly inside the repository `data/` folder:

- `challenge_completions.csv`  
  Records challenge completion outcomes (e.g., whether/when participants completed assigned challenges).

- `participant_conditions.csv`  
  Maps participants to their within and between conditions.

- `postquestions.csv`  
  Responses to questions asked after completing a challenge.

- `prequestions.csv`  
  Responses to questions asked before receiving a challenge.

- `presented_challenges.csv`  
  Log of which challenges were shown to each participant.

- `challenges_sets.csv`  
  Sets of challenges presented to each participant that was in the agency condition.

- `foto_finalQuestionnaire.csv`  
  Final questionnaire data to correct for technical issues in the original dataset for photo challenges.

Expected structure:

- `data/challenge_completions.csv`
- `data/participant_conditions.csv`
- `data/postquestions.csv`
- `data/prequestions.csv`
- `data/presented_challenges.csv`
- `data/challenges_sets.csv`
- `data/foto_finalQuestionnaire.csv`

These files will be used by the `src/data_preprocessing.ipynb` notebook to generate the processed data files required for analysis.

## How to Use This Code and Reproduce the Results

**Prerequisites:**
1. Download the published dataset from 4TU.ResearchData: 10.4121/6c139c04-13fe-4903-b2b7-091807222944
2. Extract data files into the `data/` directory of this repository
3. Ensure you have Python and Jupyter notebook installed. 

**Instructions:**
1. Install Python dependencies: `pip install -r requirements.txt` 
2. Preprocess the data using `src/data_preprocessing.ipynb`. This creates the necessary processed data files for analysis.
3. Run analysis notebooks in `src/` or `src/RQ/` folders. Further details of each notebook is given below.
   * Note that `simulation_analysis.ipynb` requires simulation results that can be generated by running `PIMORLD.ipynb` first


### File Structure and Contents

#### Root-Level Files
- **README.md** (this file): Complete documentation
- **requirements.txt**: Python dependencies for the project

#### `/data/` - Raw and Processed Datasets

**Published Dataset:**
- The files as described above should be placed in this folder.

**Processed Data:**
- `processed_samples_corrected_full.csv` - Contains processed data generated by `data_preprocessing.ipynb`
- `challenge_info.csv` - Contains challenge information (e.g., challenge IDs, mean ratings) used for analysis, also derived by `data_preprocessing.ipynb`

#### `/results/` - Figures, Trained Models, and Simulation Outputs
- `figures/` - Generated figures
- For each trained model, `<model_name>/` is a corresponding subfolder containing:
  - `model/trained_model.pkl` - Serialized trained model
  - `simulations/simulation_results.csv` - Simulation outputs for evaluation

#### `/src/` - Source Code and Analysis

**Configuration:**
- `config.py` - Central configuration file with hyperparameters, feature definitions, and constants

**Analysis Notebooks:**
- `actions.ipynb` - Challenge clustering analysis and visualization 
- `data_preprocessing.ipynb` - Data loading, cleaning, and correction
- `demographics.ipynb` - Participant demographic analysis (age, education, gender)
- `feature_selection.ipynb` - State feature and binning slection
- `PIMORLD.ipynb` - Main MORL algorithm training and simulations

**Analysis Questions for Chapter 4:**
- `RQ/simulation_analysis.ipynb` - AQ1: MORL algorithm effectiveness in balancing stakeholder objectives
- `RQ/dynamics_evaluation.ipynb` - AQ2: Learned dynamics model predictive performance

**Environment Module (`env/`):**
- `user_sim.py` - User simulation environment
- `simulate.py` - Simulation utilities for running policies and collecting results

**MORL Algorithms Module (`morld/`):**
- `pi_morld.py` - PIMORLD (Policy Iteration Multi-Objective Reinforcement Learning based on Decomposition) algorithm implementation
- `mo_pi.py` - Multi-Objective Policy Iteration solver
- `mp_selection.py` - Utilities for selecting policies from a set of Pareto-optimal policies

**Utilities Module (`utils/`):**
- `process_data.py` - Data transformation and preparation to extract (s, a, s', r) samples for MORL
- `mdp_utils.py` - MDP matrix computation (transitions, rewards, completion probabilities)
- `fs.py` - Feature selection functions
- `plot_figures.py` - Visualization utilities for simulation results
- `bayesian_analysis.py` - Bayesian hypothesis testing
- `utils.py` - General utility functions
